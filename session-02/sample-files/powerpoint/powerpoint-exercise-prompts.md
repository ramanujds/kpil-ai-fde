# Copilot in PowerPoint: Exercise Handout

**AI Developer & FDE Training | Kalpataru Projects, Ahmedabad**
Day 2, Block 4: PowerPoint | 25 minutes

In this exercise you will use Copilot in PowerPoint to create slides, write an executive summary, tidy up a messy deck and add speaker notes. You will work with two sample files about FreshCart, a made-up grocery delivery business. The business, people and numbers are all fictional.

By the end you will be able to:

1. Create a presentation from a prompt and from a document
2. Add an executive summary to an existing deck
3. Restructure and refine a deck that is long, untidy or out of order
4. Generate speaker notes
5. Check a Copilot-made deck before you present it

---

## Before You Start

- Sign in to PowerPoint with your work account and confirm you can see the Copilot button on the Home tab.
- Open the sample files from the folder your trainer shares with you.
- To create a deck from a Word document, the document usually needs to be saved in OneDrive or SharePoint. Copy the sample file there first if Copilot cannot find it.
- Use only these sample files. Do not paste real company documents, names or figures into Copilot during this exercise.
- Your screen may look slightly different from a colleague's. Button names change between versions, so look for the Copilot icon rather than an exact menu path.
- Copilot gives a different answer each time. Your deck will not match your neighbour's, and that is normal.
- Work in pairs if you can: one person types the prompts, the other reviews every slide critically. Swap halfway.

## How to Write a Good Prompt

Use the same four parts as in the Word exercise.

| Part | Question it answers | Example |
|---|---|---|
| Goal | What do I want? | "Create a 6-slide presentation" |
| Context | Who is it for, and why? | "For the procurement lead, to support a contract decision" |
| Source | What should Copilot use? | "Use only this document" |
| Expectations | What shape, length and style? | "One message per slide, short bullets, decision first" |

For presentations, always say how many slides you want. If you do not, Copilot decides for you.

## Exercise A: Create from a Prompt

Open PowerPoint and start a new blank presentation. You do not need a sample file.

**Prompt A1**

> Create a 5-slide presentation for warehouse staff about a two-week trial of an earlier 5 am dairy delivery window at FreshCart. Slides: why we are trying it, what changes for you, what we need from you, how we will measure success, and questions. Friendly and clear, short bullets, no more than four bullets per slide.

**Then try**

- "Reduce this to 3 slides without losing the request for feedback."
- "Rewrite the slide titles so each one says the main point, not just the topic."

**Think about it:** Count the slides Copilot gave you. Did it follow your slide count? Did it add facts, images or statistics that you never provided?

## Exercise B: Create from a Document

Open a new blank presentation. Use the Copilot button to create a presentation from a file, and choose FreshCart_Q3_Supplier_Performance_Update.docx. If your version has no such option, open the document in Word, copy the text and paste it into the prompt box instead.

**Prompt B1**

> Create a 6-slide presentation from this document for the procurement lead. Start with the decision needed, then the key findings, then risks, then recommendations, and end with next steps and owners. One message per slide. Use only information in the document.

**Prompt B2: Change the shape**

> Change the supplier performance slide so the four suppliers are shown in a table with on-time delivery and complaints.

**Prompt B3: Change the style**

> Make every slide title a full sentence that states the takeaway. Keep bullets to a maximum of four words each.

**Think about it:** Compare your slides with the original document. Is every number still correct? Did Copilot leave out anything important or add something the document does not say?

## Exercise C: Add an Executive Summary

Close your generated deck and open FreshCart_Supplier_Review_Draft.pptx. Read through it once yourself and note anything you would change.

**Prompt C1**

> Add an executive summary slide right after the title slide. Include the decision needed and the three most important findings. Use only information in this deck. Maximum five bullets.

**Prompt C2: Check your own understanding**

> Summarise this presentation in three sentences for someone who has two minutes.

**Think about it:** Is everything on the summary slide supported by the deck? Would a senior manager understand the decision from this slide alone?

## Exercise D: Restructure and Refine a Draft Deck

Stay in FreshCart_Supplier_Review_Draft.pptx. Use "Save As" to save a copy so you can compare with the original.

**Prompt D1: Find the problems first**

> Review this presentation. List the problems you find under these headings: Order and Flow, Too Much Text, Consistency, Missing Information, and Slides That Do Not Belong. Do not change anything yet.

**Prompt D2: Fix the flow**

> Reorder the slides into a logical flow: title, executive summary, agenda, background, supplier performance, findings for each supplier, risks, recommendations, next steps, questions. Do not delete any facts.

**Prompt D3: Reduce the text**

> On the supplier performance slide, replace the bullet list with a table. Keep only the four suppliers' on-time delivery, fill rate, complaints and price change. Move the definitions into speaker notes.

**Prompt D4: Make it consistent**

> Make all slide titles Title Case in the same font and size. Make the body text consistent across slides, with a maximum of five bullets per slide.

**Prompt D5: Remove what does not belong**

> Suggest which slides could be removed without weakening the decision, and explain why. Do not delete them yet.

**Prompt D6: Improve the next steps**

> Turn the next steps slide into a table with the columns Action, Owner and Date. If the deck does not give an owner or date, write "Not stated".

**Think about it:** Did the reordering change any meaning? Are numbers that appear on more than one slide the same everywhere? Did Copilot fill in owners or dates that the deck never gave?

## Exercise E: Speaker Notes

Stay in your refined deck.

**Prompt E1**

> Add speaker notes to every slide. Two or three sentences per slide, in plain spoken language, using only what is on the slides. Do not add new facts.

**Prompt E2: A talk track**

> Write a two-minute talk track for the supplier performance slide that I can read aloud.

**Think about it:** Read a few notes next to their slides. Do the notes say anything the slides do not?

## Exercise F: Check Before You Present

Use this checklist on every deck Copilot helps you build. It is the same habit you will use for real presentations.

| Check | Done |
|---|---|
| Numbers agree with the source and with each other across slides | |
| No facts, names, dates or owners were invented | |
| The slide count and order suit the time I have | |
| Each slide has one clear message | |
| Titles, fonts and text sizes are consistent | |
| Text is short enough to read from the back of the room | |
| Speaker notes match what is on the slides | |
| Any images or figures added by Copilot are appropriate and accurate | |
| I have looked at every slide myself | |

If you cannot tick a box, fix the slide yourself or ask Copilot to correct it, then check again.

## Stretch Prompts

If you finish early, try these on your refined deck.

- "Suggest three questions a sceptical manager might ask about this deck, and draft answers using only the deck."
- "Create a one-slide version of this deck for a busy executive."
- "Suggest a simple chart that would make the supplier comparison clearer, and tell me which numbers it would use."
- "Rewrite the speaker notes for a customer support team instead of a procurement lead."

## Remember

- Copilot builds slides quickly, but it will happily produce more slides, more text and more claims than you need.
- Tell it the audience, the slide count and the source every time.
- You are the presenter. Check every slide before you stand up.
