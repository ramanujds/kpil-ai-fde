## Planted Traps (Keep a Private Answer Key)

| Block | Trap | What trainees should notice |
|---|---|---|
| 2 Word | Summary states a number that is not in the source | Verify figures against the source |
| 3 Excel | Mixed date formats and a merged header | Data needs preparing before Copilot can analyse it |
| 4 PowerPoint | Deck is padded with too many slides | Trim to what the audience needs |
| 5 Outlook | Drafted reply agrees to something not agreed | Read drafts for commitments |
| 6 Teams | Action item has the wrong owner or date | Check recaps against what was said |
| 7 Reporting | Two sources contradict each other | Human review catches what Copilot blends over |

## Rehearsal on Your Personal Account

Run each of these once and note anything that behaves differently from the plan.

- [ ] Word: draft from prompt, rewrite in three tones, summarise the 3-page doc, improve a paragraph
- [ ] Excel: save the orders file to OneDrive with AutoSave on, format as a table, ask questions, get a chart
- [ ] Excel: confirm the planted date and header problems actually cause a visible failure, then confirm the fix works
- [ ] PowerPoint: create a deck from the Word document; restructure it; add speaker notes
- [ ] Copilot Chat: paste the email thread and run summarise, three-tone reply, shorten and follow-up
- [ ] Transcript: record the mock meeting, transcribe it if Word Transcribe is available (otherwise use the written script), then prompt for a recap and action items
- [ ] Reporting: combine the Word file, Excel data, meeting recap and email summary into a management brief; walk the review checklist
- [ ] Note which prompts gave inconsistent results, since trainees will see different outputs too

## Facilitation Reminders

- Teach prompts and judgement, not exact button locations; Copilot's interface changes often
- Outputs differ per person; use that for comparison exercises instead of treating it as a fault
- Use only synthetic files in every account; personal accounts run on the consumer service
- Review every Copilot output before it is shared
